# Line Chart

Beautifully designed line charts with customizable gradients,
animations, and interactive brush controls.

## Basic Chart


The `EdenLineCharts` component is composable. The chart
container accepts individual chart components as children.

You can add:

- `EdenLineCharts.Grid`
- `EdenLineCharts.XAxis`
- `EdenLineCharts.YAxis`
- `EdenLineCharts.Line`
- `EdenLineCharts.Tooltip`
- `EdenLineCharts.Legend`
- `EdenLineCharts.Brush`

## Installation

```bash
npx shadcn@latest add chart
```
